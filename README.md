# julia-paris.github.io

Personal academic website of Julia Paris, Ph.D. student in Economics at UC Berkeley.
Live at <https://julia-paris.github.io>.

A minimal Jekyll site, design adapted from
[Jonathan McGlone](https://github.com/jmcglone/jmcglone.github.io).

## Editing content

- **Homepage / bio** — `index.html`
- **Research** — `research.md`
- **Teaching** — `teaching.md`
- **CV (PDF)** — replace `files/Julia_Paris_CV.pdf`
- **Contact links** (Google Scholar, LinkedIn, GitHub) — fill in under `author:` in `_config.yml`
- **Look & feel** — `assets/css/main.css`; navbar in `_layouts/default.html`

## Run locally

```bash
bundle install
bundle exec jekyll serve
# open http://localhost:4000
```
